Este es un ejemplo de la página principal que se muestra después de que el preloader se completa. El preloader aparecerá durante 3.5 segundos con una animación de escaneo, seguido de un efecto glitch y desvanecimiento.

📋 Especificaciones del Preloader:

  • ✅ Overlay de pantalla completa fija (z-index: 9999)
  • ✅ Logo centrado (150-200px de ancho)
  • ✅ Fondo oscuro (#0a0a0a)
  • ✅ Línea de escaneo horizontal con efecto de brillo
  • ✅ Animación de pulso del logo
  • ✅ Efecto glitch después de 3.5 segundos
  • ✅ Desvanecimiento suave de 0.4 segundos
  • ✅ JavaScript vanilla puro (sin dependencias)

🔧 Instrucciones de Integración:

1. En tu archivo HTML principal (layout.tsx o _document.tsx):
Incluye el preloader markup antes del contenido principal.

2. Importa los archivos CSS y JS:
<link rel="stylesheet" href="/preloader.css">
<script src="/preloader.js"></script>

3. Reemplaza la ruta del logo:
Cambia el atributo src de la imagen del preloader con tu logo real.

🎮 API de Control (Opcional):

El preloader expone una API global window.PreloaderAPI para control manual:

  • PreloaderAPI.exit() - Salir del preloader manualmente
  • PreloaderAPI.reset() - Reiniciar el preloader
  • PreloaderAPI.isActive() - Verificar si el preloader está activo
